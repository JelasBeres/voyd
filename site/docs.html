VOYD Docs

Speak into the voyd.
Here's how.

VOYD is an AI agent that lives in your terminal. You say one sentence, it writes the project into your folder, and one more command puts it live. This page takes you from zero to a live site, a logo and your X content.

Just want to try it? Type an idea in the terminal on the home page. VOYD AI builds a real page in about a minute, free, 3 times a day. No wallet, no install.

01 · Quick start

Install it once. Five minutes.

  1. Have Node.js 18 or newerCheck with the command below. If it says "command not found" or a number below 18, install the LTS version from nodejs.org. 
    node -v
  2. Hold $VOYDHold at least 0.1% of the $VOYD supply in one wallet. Only buy with the contract address shown on voydagent.com or posted by @voydagent.
  3. Get your access codeGo to voydagent.com → Get access, connect the wallet, and sign one message. Signing is free and sends nothing. You get a code like VOYD-XXXXX-XXXXX-XXXXX-XXXXX.
  4. Install the CLI 
    npm i -g https://voydagent.com/voyd-agent.tgz
  5. Log inThe code locks to this computer. One wallet, one code, one device. 
    voyd login VOYD-XXXXX-XXXXX-XXXXX-XXXXX
voyd whoami
See every command any time with voyd help.

02 · Build a website

One sentence in. A real site out.

Make an empty folder for the project, go into it, and say what you want. VOYD reads and writes files only inside the folder you start it in.

mkdir my-token-site
cd my-token-site
voyd "a landing site for my memecoin $FROG: chill pixel frog, black and green, a how-to-buy section and a CA placeholder"

In about a minute you get an index.html (and any other files it needs), plus a short summary of what it built.

What makes a good sentence

Say what it is, the vibe, the colours and the sections you want. The more specific, the better it comes back.

voyd "a portfolio for a pixel artist, dark, big gallery grid, contact form"voyd "an NFT mint page for 1,000 sad cats, countdown to Friday 8pm UTC, FAQ"voyd "a waitlist page for my DAO, one email field, minimal, white on black"

Keep changing it: sessions

Type voyd on its own to open a session in the folder. Then just talk to it; it remembers the conversation.

voyd
› make the headline bigger and add a FAQ with 3 questions
› change the green to a brighter lime
› /clear     start a fresh conversation (your files stay)
› /exit      leave

03 · Preview & ship

See it. Then put it live.

voyd preview            # opens http://localhost:4321 in your browser
voyd ship my-frog       # live at https://voydagent.com/s/my-frog/

Run voyd ship with the same name again any time to update the live site. A name belongs to the wallet that shipped it first.

Rules for shipped sites: static files only (HTML, CSS, JS, images, fonts), an index.html in the folder, up to 8 MB. Sites run in a sandbox, so browser storage (localStorage, cookies) is not available. Pages that ask for seed phrases or private keys are refused.

04 · Make a logo

Three logo concepts. One command.

Run it in your project's folder, or describe the project in quotes.

voyd brand "$FROG, a chill pixel frog memecoin, black and green"

It writes a brand folder:

brand/logo-1.svgthree clearly different concepts: an abstract mark, a letterform, a pictorial idea
brand/logo-2.svgvector SVG, works at 32px and on a billboard
brand/logo-3.svgno text inside, two colours max
brand/x-profile.txtdisplay name, 3 bios, a pinned-post idea
brand/dex-info.txttagline, short and long description for DEX listings
brand/palette.txtyour colours with hex codes
brand/index.htmlall three logos side by side, big and small, on dark and light

To compare them, run voyd preview and open http://localhost:4321/brand/. Want changes? Open a session (voyd) and say "make logo 2 bolder and use it as the X avatar".

05 · X content

Your launch, written.

voyd x "$FROG, a chill pixel frog memecoin launching on Pons"
x/profile.txtdisplay name, 3 bios, header idea, the pinned post
x/launch-thread.txta 5 to 7 post launch thread that opens with a hook
x/posts.txt10 posts for your first two weeks, each with when to post it and why
x/cards.html3 post images at 1600×900, ready to screenshot and attach

Open the images with voyd preview → http://localhost:4321/x/cards.html, then screenshot each one. The contract address is left as <CA>: paste yours in before posting.

Tip: run voyd brand first, then voyd x in the same folder. VOYD reads the brand files and keeps the same name, voice and colours.

06 · Audit a token

Check it before you ape.

voyd audit 0xYourTokenContractAddress

VOYD reads the contract straight from Robinhood Chain: owner, mint / fee / blacklist / pause functions in the bytecode, upgradeable proxies, Pons launch status, how much the deployer holds, how much is burned, and the verified source when there is one. You get a score from 0 to 100 with a verdict (SAFE, CAUTION or DANGER) and the reasons.

It is a fast, honest first look, not a professional audit and not financial advice.

07 · Roast & fix

Brutal review. Then the fix.

voyd roast https://any-website.com     # score + what's wrong, saved to .voyd/roast.txt
voyd fix                               # improves the site in this folder using that roast

Roast your own live site, then run voyd fix in the folder that has its code. Without a roast, voyd fix does its own review first.

08 · The engine

What runs where.

VOYD AI is the model behind every command. It runs on voydagent.com, so you don't need an API key or a paid AI plan: holding $VOYD is the key.

Your filesstay on your computer. The CLI reads and writes only inside the folder you run it in, and sends the model only what it needs for the task.
Your codeyour access code is kept in ~/.voyd/config.json, readable only by you.
Daily limits300 agent steps, 40 audits + roasts and 30 ships per code per day. They reset at 00:00 UTC.
Access checkyour wallet's $VOYD balance is re-checked regularly. Sell below 0.1% and the code stops working; buy back and get a new code.

09 · Troubleshooting

If something doesn't work.

command not found: voydnpm's global folder isn't on your PATH. Run npm config get prefix and add its bin folder to PATH, or reopen the terminal.
Unknown access codeCheck for typos, or get a fresh code at Get access. A new code replaces the old one.
Used on another deviceEach code locks to the first computer. To switch, get a new code with the same wallet.
No longer holds enoughThe wallet behind the code is under 0.1% of supply.
Daily limit reachedWait until 00:00 UTC.
Session too longType /clear in the session. Your files stay.

Still stuck? Ask Ask the voyd (bottom right on the home page) or message @voydagent. There is no Telegram, and nobody from VOYD will ever DM you first or ask for your seed phrase.
